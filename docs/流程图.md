## 1. 系统整体流程

```mermaid
flowchart TB
    subgraph 用户侧
        A[用户登录] --> B[上传文档 8种格式]
        B --> C[输入自然语言问题]
        C --> D[查看流式答案 +展开引用原文]
        D --> E[👍👎 反馈]
    end

    subgraph 文档处理管线
        B --> F[格式识别]
        F --> G[解析器分发]
        G --> H[语义分块 512tokens]
        H --> I[向量嵌入]
        I --> J[(ChromaDB)]
        I --> K[(SQLite元数据)]
    end

    subgraph 检索与生成管线
        C --> L{意图分类 准确率93%}
        L -- 简单 --> M[Direct检索 ~0.25s 零Token]
        L -- 复杂 --> N[HyDE检索 ~1.9s]
        M --> O[去重+重排序]
        N --> O
        O --> P{有结果?}
        P -- 是 --> Q[拼接上下文]
        P -- 否 --> R[提示未找到]
        Q --> S{MCP路由 需要联网?}
        S -- 是 --> T[Tavily外部搜索]
        S -- 否 --> U[纯本地]
        T --> V[本地+外部融合]
        V --> W[LLM流式生成]
        U --> W
        W --> D
    end

    subgraph 记忆管线
        D --> X[LLM抽取3-8个概念]
        X --> Y[工作记忆 会话上下文]
        X --> Z[(情景记忆 ChromaDB)]
        X --> AA{Neo4j可用?}
        AA -- 是 --> BB[(语义记忆 Neo4j图谱)]
        AA -- 否 --> CC[自动降级 不报错]
        Y --> DD{超10轮?}
        DD -- 是 --> EE[LLM压缩 Token-75%]
    end

    subgraph 反馈闭环
        E --> FF[(SQLite)]
        FF --> GG[监控看板 满意率/延迟/成本]
        GG --> HH[数据驱动迭代]
    end
```

## 2. 检索策略决策流程

```mermaid
flowchart TD
    A[用户问题] --> B{复杂度分类器<br/>93%准确率}
    
    B -->|简单事实查询| C[Direct]
    B -->|复杂口语查询| D[HyDE]
    
    C --> C1[embed问题]
    C1 --> C2[(ChromaDB向量检索)]
    C2 --> C3[Top-20候选]
    
    D --> D1[LLM生成假设文档<br/>200-400字]
    D1 --> D2[embed假设文档]
    D2 --> D3[(ChromaDB向量检索)]
    D3 --> D4[Top-20候选]
    
    C3 --> E[BGE Reranker 重排序]
    D4 --> E
    
    E --> F{相似度>0.2?}
    F -- 否 --> G[提示: 未找到相关内容]
    F -- 是 --> H[Bigram Jaccard去重<br/>阈值0.65]
    H --> I[Top-10结果]
    
    I --> J{MCP外部搜索?}
    J -- 触发 --> K[Tavily搜索]
    J -- 不触发 --> L[纯本地结果]
    K --> M[外部去重 + 交错排列<br/>L1→E1→L2→E2]
    M --> N["拼接上下文<br/>(N)本地 (E)外部"]
    L --> N
    
    N --> O[LLM流式生成]
    O --> P[返回答案+引用]
```

## 4. 数据驱动迭代闭环

```mermaid
flowchart LR
    subgraph 线上运行
        A[用户提问] --> B[系统回答]
        B --> C[用户👍👎]

    subgraph 迭代决策

        L --> O
        M --> O
        N --> O
    end
    
    O --> A
    
    I --> P[9轮迭代结果<br/>MRR 0.42→0.75<br/>+79%]
```

## 6. 文档导入处理流程

```mermaid
flowchart TD
    A[用户上传文件或URL] --> B{格式检测}
    
    B --> C[PDF: PyMuPDF]
    B --> D[Word: python-docx]
    B --> E[Markdown: 标题感知分割]
    B --> F[TXT: chardet编码检测]
    B --> G[PPT: python-pptx]
    B --> H[CSV: csv模块]
    B --> I[XLSX: openpyxl]
    B --> J["URL: Trafilatura<br/>失败用BeautifulSoup兜底"]
    
    C --> K[解析为纯文本]
    D --> K
    E --> K
    F --> K
    G --> K
    H --> K
    I --> K
    J --> K
    
    K --> L{内容为空?}
    L -- 是 --> M["拒绝: 提示空文件"]
    L -- 否 --> N["语义分块<br/>SemanticSplitterNodeParser"]
    
    N --> O["批量嵌入<br/>10条每批"]
    O --> P{嵌入成功?}
    P -- 是 --> Q["ChromaDB入库<br/>SHA256分块ID"]
    P -- 否 --> R["重试或跳过<br/>记录错误"]
    
    Q --> S["SQLite元数据<br/>doc_id+格式+分块数+耗时"]
    
    S --> T["页面展示<br/>加载完成+分步耗时"]
```
